# Token

Прототип кабинета для подготовки к экзамену с репетитором. Роли разделены:
вы заходите либо репетитором, либо учеником, и видите разные кабинеты.

Открывается двойным кликом по `login.html` — сборка не нужна, зависимостей нет.

## С чего начать

База пустая: ни одного ученика или репетитора не заведено заранее.

1. **Зарегистрируйтесь репетитором** на `login.html` — вкладка «Регистрация», роль «Репетитор».
2. В кабинете внизу — раздел **«Приглашения»**, нажмите «Новая ссылка» → «Создать».
   Скопируйте ссылку.
3. **Выйдите** и зарегистрируйтесь ещё раз — уже **учеником**, с другим email.
4. Откройте скопированную ссылку — увидите, к кому и на какой предмет присоединяетесь.
   Нажмите «Присоединиться».
5. Вернитесь **репетитором** (на экране входа есть быстрое переключение между
   аккаунтами этого устройства). В блоке «Сегодня» — **«Назначить занятие»**.
6. На странице занятия: **добавьте ссылки** (есть заготовки для Телемоста, Zoom,
   Excalidraw, Miro) и **прикрепите задания из банка**.
7. Войдите **учеником** — занятие видно, кнопка «Подключиться» ведёт на созвон,
   задания открываются. Пишите код в редакторе, вводите ответ, жмите «Проверить».
8. Откройте в соседней вкладке занятие **репетитором** — он видит черновик кода
   ученика с задержкой около двух секунд.

Родитель заведён как роль, но закрыт заглушкой: на экране входа отмечен как недоступный.

## Роли

| Роль | Кабинет | Что может |
|---|---|---|
| Репетитор | `tutor.html` | ученики, группы, приглашения, занятия, проверка работ, банк задач |
| Ученик | `index.html` | занятия, домашние задания, решение задач, статистика, профиль |
| Родитель | `parent.html` | заглушка — спроектирован, не собран |

Разделение настоящее: ученик, открывший `tutor.html`, вернётся к себе; гость уйдёт
на страницу входа. Проверяется на каждой странице через `Auth.require(role)`.

## Что работает по-настоящему

- **Регистрация и вход** с паролем, сессия переживает перезагрузку.
- **Приглашения** — ученик привязывается к репетитору или вступает в группу по ссылке.
  Проверяются срок, лимит переходов, отзыв, вместимость группы и повторное вступление.
- **Занятие** — репетитор назначает время, добавляет ссылки (созвон, доска, материал),
  прикрепляет задания из банка. Всё сразу видно ученику.
- **Решение задачи** — таймер активного времени (пауза после 2 минут без ввода),
  черновик кода сохраняется, автопроверка ответа по правилу задачи
  (`exact`, `ci`, `set`, `numeric` с допуском).
- **Наблюдение** — репетитор видит черновик кода ученика, снапшот раз в 2 секунды.
- **Статистика** — считается из решённых задач: точность, серия дней, темы,
  посещаемость и сводка по номерам заданий («№17 — 3 ч 10 мин, 77% верных»).
- **Группы** — общие занятия и задания, статистика по каждому ученику отдельно.

## Банк задач

91 задача, покрыты все номера обоих предметов. Задачи **генерируются**: числа в
условии и ответ считаются из одного зерна, поэтому ответы верные и автопроверка
настоящая. Проверено — все 80 автопроверяемых задач проходят сверку со своим эталоном.

Это временный банк вместо парсера. Когда парсер появится, он положит записи той же
формы в ту же таблицу — экраны менять не придётся. Приёмник импорта (JSON с валидацией)
уже готов на странице «Банк задач».

## Устройство

```
assets/db.js     справочники (предметы, темы, банк) + состояние в localStorage
assets/auth.js   регистрация, вход, роли, защита страниц
assets/core.js   агрегаты и мутации: статистика, занятия, группы, приглашения
assets/ui.js     оболочка: сайдбар по роли, хелперы вёрстки
```

Ни одна цифра на экранах не написана в разметке — всё считается в `core.js`
функциями, названными как таблицы доменной модели: `topicMastery`, `dailyActivity`,
`taskNumberStats`, `attendance`, `groupStats`. Чтобы подключить бэкенд, меняется
тело `DB.load()`.

**Новый предмет — запись в данных, а не правка кода.** Номера заданий, максимумы
баллов и шкала перевода лежат в `subject.exam`. В прототипе два предмета с разными
сетками (информатика — 27 заданий, профильная математика — 18), обе работают через
один код.

## Документация

В [`docs/`](docs/) — три варианта архитектуры, доменная модель, жизненные циклы и роли,
схема живой сессии занятия. Файлы `.excalidraw` открываются на
[excalidraw.com](https://excalidraw.com) перетаскиванием; рядом `.preview.svg` для
любого браузера. Текстовый разбор — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Чего пока нет

Платежи, парсер банка задач, кабинет родителя, редактирование профиля.

Пароли хешируются примитивно и лежат в localStorage — этого достаточно, чтобы
показать разделение ролей, и недостаточно для боевой версии: там нужен сервер,
argon2 и сессия в httpOnly-куке.

Кнопка «сбросить всё» в правом нижнем углу удаляет аккаунты и данные этого браузера.
