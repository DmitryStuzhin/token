# Архитектура модульного монолита

Статус: реализовано в этапе 1  
Дата: 2026-08-08

## Границы

- `server/` — composition root, HTTP/WebSocket transport и legacy session middleware;
- `modules/*/domain` — чистые правила и автоматы состояний;
- `modules/*/application` — use cases и repository ports;
- `modules/*/policy` — проверки доступа к агрегатам;
- `modules/*/infrastructure` — SQLite adapters и in-process event dispatcher;
- `shared/` — совместимый read-side для существующего frontend.

Направление зависимостей: transport → application → domain. Infrastructure
реализует application ports и подключается только в composition root.
`dependency-cruiser` запрещает циклы, импорт infrastructure из application и
зависимость domain от Express/SQLite.

## Конкурентная запись

`Invite`, `Lesson`, `Assignment` и `Attempt` имеют целочисленный `version`.
Запись выполняется как `UPDATE ... WHERE id = ? AND version = ?` с увеличением
версии. Нулевое число изменённых строк преобразуется в HTTP 409. Это защищает
агрегаты от lost update уже на SQLite и переносится в PostgreSQL без изменения
application-контрактов.

## События

Envelope содержит `eventId`, `eventName`, `eventVersion`, `occurredAt`,
`aggregateId`, `correlationId`, `payload`. Сейчас dispatcher работает внутри
процесса. События: `UserRegistered`, `InviteAccepted`, `LessonCompleted`,
`AssignmentPublished`, `AttemptChecked`. На этапе outbox тот же контракт будет
сохраняться транзакционно и доставляться worker-ом.
