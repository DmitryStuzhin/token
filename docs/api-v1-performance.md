# API v1 — контроль производительности этапа 3

Дата: 2026-08-09. Контур: локальное приложение на Node.js и PostgreSQL 16.4 в
Docker, актуальная пользовательская база после cutover.

## Методика

Команда `npm run baseline:api-v1` отправляет 100 запросов к гостевому экранному
DTO `/api/v1/screens/login` с concurrency 10. Это десятикратная стартовая
одновременная нагрузка, зафиксированная в критерии выхода этапа. Скрипт также
сравнивает размер ответа с legacy `/api/state`.

## Результат

| Метрика | Значение |
|---|---:|
| p50 | 37,12 мс |
| p95 | 60,97 мс |
| p99 | 63,66 мс |
| max | 66,45 мс |
| API v1 screen payload | 2 614 байт |
| legacy snapshot payload | 44 681 байт |
| сокращение payload | 94,1% |

Критерий `p95 ≤ 300 мс` выполнен с запасом. Это локальный контрольный профиль,
а не обещание production latency: перед публичным запуском профиль повторяется
в staging с сетевой задержкой, TLS, production pool и репрезентативным объёмом
данных.
