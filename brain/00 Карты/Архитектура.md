# Архитектура

> Один долгоживущий Node-процесс: HTTP + WebSocket + PostgreSQL.
> Это «вариант A» из `docs/ARCHITECTURE.md`.

Это текущая архитектура прототипа. Целевая архитектура массовой платформы
зафиксирована в [[ADR-010 Целевая событийная платформа]] и
`docs/ТЕХНИЧЕСКОЕ ЗАДАНИЕ.md`.

## Слои

[[Сервер]] — `server/index.js`, маршрутизация и защита страниц
[[База данных]] — `packages/db`, PostgreSQL schema/migrator и repository adapters
[[HTTP API]] — `server/api-v1.js`, OpenAPI-контракт и все операции
[[Read-модели API v1]] — четыре восстанавливаемые PostgreSQL-проекции
[[Модульные границы]] — domain/application/policy/repository adapters
[[Внутренние события]] — event envelope и in-process dispatcher
[[Живой канал]] — `server/live.js`, комнаты занятий
[[Общий код]] — `shared/`, один код агрегатов на сервере и клиенте
[[Клиент]] — `public/`, рендер из контекстных screen DTO
[[Production-развёртывание]] — Timeweb VPS, S3 и состояние боевого контура
