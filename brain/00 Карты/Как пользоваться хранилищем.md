# Как пользоваться хранилищем

> Граф — первичный источник контекста и развиваемая память проекта.
> Обязательный порядок работы описан в [[Протокол работы с графом]].

## Открыть

Obsidian → «Открыть папку как хранилище» → выбрать `brain/`.
Начать с [[Карта проекта]].

## Настройки, без которых граф хуже

- **Файлы и ссылки → Формат новой ссылки:** кратчайший путь
- **Файлы и ссылки → Использовать вики-ссылки:** включить
- **Граф → Группы:** добавить цвета по тегам (ниже)

## Почему граф один, а не четыре

Разделить хранилище по ролям не получится без потерь: [[Lesson]],
[[TaskAttempt]] и [[Enrollment]] принадлежат сразу двум ролям. В четырёх
хранилищах эти записи пришлось бы дублировать, и они разъехались бы
через неделю.

Вместо этого — один граф и **фильтры**. В поиске графа:

```
tag:#роль/репетитор
tag:#роль/ученик
tag:#роль/родитель
tag:#роль/админ
```

Так получается «граф роли» без дублирования записей.

## Цветовые группы для графа

| Запрос | Цвет | Что подсветит |
|---|---|---|
| `tag:#тип/карта` | жёлтый | точки входа |
| `tag:#тип/сущность` | синий | данные |
| `tag:#тип/экран` | зелёный | интерфейс |
| `tag:#тип/процесс` | фиолетовый | сценарии |
| `tag:#тип/решение` | красный | ADR |
| `tag:#статус/план` | серый | ещё не сделано |

## Как искать быстро

- **По слою:** `path:"20 Домен"`
- **По роли:** `tag:#роль/ученик`
- **Что не готово:** `tag:#статус/план OR tag:#статус/заглушка`
- **Где живёт код:** ищите `источник:` в свойствах записи

## Правила ведения

1. Всегда начинать поиск информации с графа — [[Протокол работы с графом]].
2. Если информации нет или она неверна, сразу добавить либо исправить её.
3. После изменения проекта обновить связанные записи и карты в той же задаче.
4. Одна запись — одно понятие. Заголовок = имя понятия.
5. Первая строка после заголовка — определение в одну фразу.
6. Ссылки только осмысленные. Связь «упоминается рядом» не связь.
7. У записи про код всегда есть поле `источник` с путём к файлу.
8. Решения не переписываются, а дополняются: см. [[Решения]].
9. Новое слово — сразу в [[Глоссарий]], иначе через месяц их будет два.
