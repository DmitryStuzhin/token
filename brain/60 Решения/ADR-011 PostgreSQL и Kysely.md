# ADR-011 — PostgreSQL и Kysely

## Решение

Production-хранилище — PostgreSQL. Типизированные запросы строятся через Kysely,
а схема изменяется явными версионированными SQL-миграциями из `packages/db`.
SQLite остаётся временным adapter для разработки, тестов и rollback-window.

## Почему

- PostgreSQL снимает ограничение одного писателя и поддерживает несколько API-процессов.
- Явный SQL сохраняет контроль над constraints, индексами, `EXPLAIN` и rollback.
- Kysely даёт типизацию без скрытого управления схемой.
- Один repository contract удерживает одинаковое поведение двух адаптеров.

## Последствия

Нужны `DATABASE_URL`, миграции перед запуском, backup и проверяемый cutover.
Удалять SQLite можно только после стабильного окна. Kafka и Redis к этому решению
не привязаны и вводятся отдельно по метрикам роста.
