# Проведение занятия

> От создания до закрытия.

## 1. Назначить

[[Экран Сегодня]] → «Назначить занятие»: ученик или группа, время,
длительность → `POST /api/lessons` → появляется [[Lesson]].

## 2. Наполнить

- [[LessonLink|Ссылки]]: созвон, доска, материалы. Есть заготовки.
- Задачи из банка: `POST /api/lessons/:id/tasks`.
  Сервер сразу создаёт [[TaskAttempt|попытки]] всем участникам —
  ученик видит задание немедленно.

## 3. Вести

Репетитор видит черновик кода ученика → [[Живой канал]].
Для группы — переключение между участниками.

## 4. Закрыть

«Завершить» → `status: done` → [[LessonAttendance|посещаемость]] всем
участникам и списание занятия с [[Subscription|абонемента]].
