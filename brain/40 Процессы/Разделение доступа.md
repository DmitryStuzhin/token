# Разделение доступа

> Кто что видит и почему нельзя обойти через браузер.

## Три рубежа

1. **Страницы.** `server/index.js` отдаёт разметку кабинета только
   с сессией. Гость получает `302` до отдачи файла.
2. **Данные.** `snapshot(user)` в `server/db.js` собирает срез: ученик
   получает только своё, репетитор — только своих учеников.
3. **Действия.** Каждый маршрут проверяет роль и владение объектом.

## Примеры

| Попытка | Ответ |
|---|---|
| ученик создаёт занятие | `403` |
| ученик правит чужую попытку | `403` |
| репетитор трогает чужого ученика | `403` |
| гость запрашивает состояние | срез без личных данных |
