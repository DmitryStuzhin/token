# Ученик

> `role: 'student'`. Решает задачи, ходит на занятия, видит только свои данные.

Кабинет: `/index.html`. Профиль в БД — [[StudentProfile]].

## Что может

- Присоединиться к репетитору по ссылке → [[Приглашение и привязка]]
- Открыть занятие, перейти по [[LessonLink|ссылкам занятия]]
- Решать задачи: черновик, ответ, автопроверка → [[Решение задачи]]
- Смотреть свою статистику → [[Производные агрегаты]]
- Менять настройки уведомлений → [[NotificationPref]]

## Чего не может

- Создать [[Lesson|занятие]] или [[Assignment|задание]] — `403`
- Увидеть чужие работы — их нет в его срезе
- Изменить чужую [[TaskAttempt|попытку]] — `403`
- Узнать эталонный ответ до проверки → [[ADR-006 Ответы не покидают сервер]]
