# Гость

> Посетитель без действующей [[Session|сессии]].

## Что видит

Только `/login.html`. Любая другая страница `*.html` отдаёт `302` на вход
с параметром `next` — после входа вернёт туда, куда шёл.

Проверка стоит **до отдачи файла**, в `server/index.js`:
разметка кабинета гостю не уходит вообще.

## Что доступно по API

- `GET /api/state` — срез без пользовательских данных, но со справочниками
  (предметы, темы, банк задач без ответов)
- `GET /api/auth/roles`, `POST /api/auth/register`, `POST /api/auth/login`

Всё остальное — `401`.
