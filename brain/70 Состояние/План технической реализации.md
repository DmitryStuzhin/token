## Текущий прогресс

Этапы 0 и 1 завершены 2026-08-08. Зафиксированы окружение и baseline, добавлены
`createApp()`, health/readiness, request ID, структурированные логи, безопасные
HTTP errors, reusable fixtures, Node/Supertest/Playwright/WebSocket e2e и полный
CI. GitHub `master` защищён обязательными проверками `quality`,
`dependency-review`, `secret-scan`, запретом force-push и удаления.

Этап 1 добавил strict TypeScript, npm workspaces с единым lockfile, Zod config,
Prettier/ESLint/import boundaries, [[Модульные границы]], автоматы состояний,
optimistic `version` и [[Внутренние события]]. SQL вынесен из HTTP routes.

Baseline: `docs/performance-baseline.md`.

Реализация этапа 2 завершена 2026-08-08: [[ADR-011 PostgreSQL и Kysely]],
нормализованная PostgreSQL-схема, versioned migrator, UUIDv7, repository adapters,
идемпотентный ETL с двумя rehearsal, backup/verify и
[[Миграция SQLite в PostgreSQL|cutover/rollback runbook]]. HTTP API и интерфейс
сохранены; полный сценарий проходит на PostgreSQL.

Cutover текущей локальной БД выполнен 2026-08-08: приложение работает с
PostgreSQL 16.4 в Docker, перенос и повторный verify успешны. SQLite удаляется
только после стабильного rollback-window. Для публичного размещения потребуется
повторить runbook с managed `DATABASE_URL`.

Этап 3 завершён 2026-08-09: [[ADR-012 Контекстный API v1]], OpenAPI 3.1,
Problem Details, validation, cursor pagination, фильтры, сортировка,
`Idempotency-Key`, `ETag/If-Match`, generated typed client и четыре
[[Read-модели API v1|восстанавливаемые read-модели]]. Все 16 страниц работают
через screen DTO и не запрашивают `/api/state.js`. Contract/integration тесты —
19/19, browser E2E — 3/3. При 100 запросах и concurrency 10: p95 60,97 мс,
payload уменьшен на 94,1%. Следующий этап — production Identity и безопасность.

## Принцип

На старте до 200 пользователей — модульный монолит и PostgreSQL. Сложная
инфраструктура вводится после подготовки контрактов и при подтверждённых
технических триггерах: [[ADR-010 Целевая событийная платформа]].
