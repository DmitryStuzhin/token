# Риски

> Что сломается раньше всего и насколько это больно.

## Высокие

| Риск | Последствие | Смягчение |
|---|---|---|
| Нет HTTPS | сессия и пароль в открытом виде | TLS + `secure: true` до выхода в сеть |
| Нет ограничения попыток входа | перебор пароля | счётчик на IP и email |
| Backup не запущен по расписанию в production | потеря данных | готовые backup/verify CLI + внешний scheduler и off-site storage |
| Утечка ссылки-приглашения | присоединится посторонний | лимит переходов, отзыв, срок |
| Legacy `/api/state` пока доступен для rollback | новый код может случайно вернуть зависимость от полного snapshot | E2E запрещает запрос frontend; endpoint удалить после окна наблюдения |
| Ошибка production cutover | простой или расхождение данных | две rehearsal, freeze, counts/orphans/checksum, rollback runbook |
| Один процесс и локальные WebSocket-комнаты | предел масштабирования и потеря live-состояния при релизе | stateless API, Redis realtime-контур, Kafka для критичных событий |

## Средние

| Риск | Последствие |
|---|---|
| Время меряет клиент | статистику можно завысить (потолок 6 часов ограничивает) |
| Нет журнала действий | спор «кто удалил» не разобрать |
| WebSocket-комнаты в памяти | при перезапуске наблюдение обрывается (клиент переподключается сам) |
| SQLite остаётся rollback-контуром | две реализации нужно поддерживать до конца окна |
| Hosted PostgreSQL ещё не подключён | локальная БД зависит от одного Docker volume |
| Idempotency records пока без TTL cleanup | таблица будет бесконечно расти | добавить retention worker до публичной эксплуатации |
| Синхронный полный rebuild проекций в trigger | стоимость записи растёт вместе с данными | измерять p95; перейти на incremental outbox при достижении порога |
| Нет tenant-модели | невозможно безопасно обслуживать организации |

## Низкие, но заметные

- Пароль от 4 символов — слишком мягко
- Нет подтверждения email: опечатка в адресе = потерянный аккаунт
- `sameSite: lax` вместо CSRF-токена
