# Глоссарий

> Одно понятие — одно слово. Если в коде и в разговоре слова разные,
> это записано здесь.

| В разговоре | В коде | Запись |
|---|---|---|
| привязка | `enrollment` | [[Enrollment]] |
| попытка, работа, решение | `attempt` | [[TaskAttempt]] |
| приглашение, ссылка, код | `invite` | [[Invite]] |
| занятие, урок | `lesson` | [[Lesson]] |
| домашка, д/з | `assignment` | [[Assignment]] |
| задача из банка | `task` | [[Task]] |
| номер задания | `number` (не `egeNumber`) | [[Subject]] |
| активное время | `active_seconds` | [[ADR-007 Активное время вместо часов на стене]] |
| срез состояния | `snapshot` | [[База данных]] |
| полное состояние | `fullState` | [[База данных]] |

## Слова, которых лучше избегать

- «студент» — в проекте [[Ученик]] (`student` только в коде)
- «учитель» — [[Репетитор]]
- «админка» — такой роли нет, есть [[Экран Банк задач]]
- «ЕГЭ-номер» — просто номер задания, сетка своя у каждого [[Subject|предмета]]
