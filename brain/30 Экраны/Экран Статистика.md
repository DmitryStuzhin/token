# Экран Статистика

> Всё, что считается из решённых задач. Открывается тремя ролями,
> но данные всегда одного ученика.

## Блоки

- Показатели за период (неделя / месяц / 3 месяца / всё время)
- График [[MockExam|пробников]] с пунктиром цели
- Темы с изменением за месяц → TopicMastery
- Хитмап активности за 4 недели и серия → DailyActivity
- Кольцо посещаемости → [[LessonAttendance]]
- **Сводка по номерам заданий** → TaskNumberStats
- Последние работы
- Самостоятельные попытки `practice` учитываются даже без привязки ученика к репетитору

## Кто ещё может открыть

[[Репетитор]] — со своим учеником в параметре `student`.
Сервер всё равно отдаёт только своих: чужого id в срезе нет.
