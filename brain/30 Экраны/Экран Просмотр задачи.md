# Экран Просмотр задачи

> Общая карточка условия по адресу `/task-view.html?task=<id>` без раскрытия эталонного ответа.

## Репетитор

- Открывает карточку по названию из [[Экран Банк задач]] или из занятия.
- Видит условие, предмет, номер, тему, сложность, способ проверки и источник.
- Возвращается в банк; эталонный ответ не передаётся в браузер.

## Ученик

- Может открыть условие без запуска таймера и без создания попытки.
- Если задача уже выдана в домашней работе или на занятии, переходит на [[Экран Задача]].
- Если задача не выдана, видит только карточку и пояснение о доступе к решению.

## Данные и безопасность

Экран получает публичную форму [[Task]] через screen bootstrap `task-view`.
Поле эталонного ответа отсутствует согласно [[ADR-006 Ответы не покидают сервер]].
