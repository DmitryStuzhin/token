# Экран Группа

> Одна [[Group|группа]] подробно.

## Блоки

- Показатели: состав, средняя точность, посещаемость, просрочки
- **Участники** — по каждому свои цифры, не усреднённые
- Занятия группы с числом присутствовавших
- Задания группы: «сдали 3 из 5»
- Ссылка набора с копированием

## Главная мысль

Статистика в таблице участников — **не групповая**. Она считается по каждому
ученику отдельно: [[ADR-004 Группа не владеет статистикой]]
