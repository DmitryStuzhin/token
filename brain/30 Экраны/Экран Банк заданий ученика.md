# Экран Банк заданий ученика

Доступен любому зарегистрированному ученику, даже без связи с репетитором.
Первый шаг — выбор предмета. После выбора показывается по одной позиции на каждый
номер экзамена. Нажатие на номер открывает все его задачи с фильтрами сложности
и даты публикации. Задача в списке открывает [[Экран Задача]]. Решённые задачи
помечаются, а повторное открытие ведёт в сохранённую попытку `practice`.
В карточке видны название, метаданные и полное условие, но поле ответа и редактор
доступны только после перехода на страницу решения.
Повторного переключателя предметов внутри каталога нет; смена предмета выполняется
возвратом на первый шаг.
При возврате браузерной кнопкой «назад» кнопки решения принудительно активируются:
Safari может восстановить страницу из BFCache вместе с временным `disabled`.
