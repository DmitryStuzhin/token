# Enrollment — привязка ученика к репетитору

> **Ядро модели.** Одна запись = один ученик у одного репетитора
> по одному предмету.

## Поля

| поле | смысл |
|---|---|
| `student_id` → [[StudentProfile]] | кто учится |
| `tutor_id` → [[TutorProfile]] | у кого |
| `subject_id` → [[Subject]] | по какому предмету |
| `status` | `active` · `paused` |
| `source` | `invite` — почти всегда |

## Почему это отдельная сущность

Не поле `tutor_id` в профиле ученика, потому что:

- у ученика бывает **несколько предметов** и разные репетиторы
- смена репетитора не должна стирать историю: старая запись закрывается,
  создаётся новая
- через привязку висят [[Lesson|занятия]] и [[Assignment|задания]]

## Кто создаёт

Только приём приглашения: [[Приглашение и привязка]].
Вручную — некому, роли [[Админ|админа]] нет.
