# TutorProfile — профиль репетитора

> Рабочая часть [[User]] с ролью `tutor`.

## Поля

| поле | смысл |
|---|---|
| `subjects` | JSON-массив id предметов, которые ведёт |
| `years_exp` | опыт в годах |
| `rate` | ставка за занятие |
| `meeting_url` | постоянная ссылка на созвон, если есть |

## Где используется

- Список предметов ограничивает выбор при выпуске [[Invite|приглашения]]
  и создании [[Group|группы]]
- `tutor_id` в [[Enrollment]], [[Group]], [[Lesson]], [[Invite]]
