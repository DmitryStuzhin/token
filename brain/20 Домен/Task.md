# Task — задача из банка

> Формулировка и эталонный ответ. Общая для всех, у ученика её копии нет.

## Поля

| поле | смысл |
|---|---|
| `subject_id`, `number` | предмет и номер в его сетке |
| `statement` | условие |
| `answer` | **эталон, наружу не отдаётся** |
| `answer_type` | `number` · `string` · `set` |
| `compare` | `exact` · `ci` · `set` · `numeric` |
| `tolerance` | допуск для `numeric` |
| `auto_check` | `false` — проверяет репетитор |

## Откуда берётся

Сейчас **генерируется**: `shared/domain.js` считает числа в условии и ответ
из одного зерна, поэтому автопроверка настоящая. 91 задача, покрыты все
номера обоих предметов.

Парсер не написан; приёмник импорта готов — [[Экран Банк задач]].

## Главное правило

Поле `answer` вырезается в `snapshot()` и в `GET /api/tasks`.
