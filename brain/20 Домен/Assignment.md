# Assignment — домашнее задание

> Пакет задач со сроком. Как и [[Lesson]], адресуется привязке или группе.

## Поля

`enrollment_id` **или** `group_id` · `lesson_id` (с какого занятия) ·
`title` · `due_at` · `task_ids` (JSON)

## Статус не хранится

Вычисляется по попыткам конкретного ученика в `decorateAssignment()`:

| условие | статус |
|---|---|
| все задачи закрыты | `checked` |
| есть отправленные на ручную проверку | `submitted` |
| срок прошёл, не всё сдано | `overdue` |
| что-то начато | `in_progress` |
| иначе | `issued` |

Поэтому у группового задания **у каждого свой статус**.
