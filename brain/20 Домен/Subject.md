# Subject — предмет

> **Несёт сетку экзамена.** Поэтому новый предмет — запись в таблице,
> а не правка кода.

## Поля

| поле | смысл |
|---|---|
| `id`, `name`, `short`, `color` | как показывать |
| `exam.parts[]` | `{ number, maxPoints, topicId }` — номера заданий |
| `exam.scale[]` | первичный балл → тестовый |

## Что из этого следует

- Покрытие банка задач считается по `parts`, а не по числу «27»
- Балл пробника переводится по `scale` этого предмета
- Сводка по номерам заданий строится для любого предмета одинаково

Сейчас два предмета с разными сетками: информатика (27 заданий, максимум 29
первичных) и профильная математика (19 заданий, максимум 32) по спецификации ЕГЭ 2026.

В PostgreSQL справочник синхронизируется из `shared/domain.js` при запуске
через `server/reference-data.js`. Это обязательно и для пустой production-базы:
без справочника регистрация репетитора и выбор предмета в приглашении невозможны.
Репетиторам, зарегистрированным в период отсутствия справочника, однократно
назначаются все доступные предметы; уже сделанный выбор не изменяется.
