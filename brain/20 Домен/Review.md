# Review — проверка репетитором

> Не отдельная таблица: поля `review_score`, `review_comment`,
> `reviewed_by`, `reviewed_at` внутри [[TaskAttempt]].

## Когда нужна

Только для задач с `auto_check = false` — там, где нужен разбор решения
(№27 по информатике, задачи с полным решением по математике).

## Что делает

`POST /api/attempts/:id/review`: ставит `status = checked`,
`is_correct = score > 0`, пишет балл и комментарий.

Сервер проверяет, что ученик действительно **свой**: через [[Enrollment]]
или [[GroupMember]].
