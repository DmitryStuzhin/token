# Lesson — занятие

> Событие в расписании. Адресуется **либо** привязке, **либо** группе.

## Поля

| поле | смысл |
|---|---|
| `enrollment_id` **или** `group_id` | кому; заполнен ровно один |
| `subject_id`, `tutor_id` | денормализовано для быстрых выборок |
| `starts_at`, `duration_min` | когда |
| `status` | `planned` · `done` · `moved` · `missed` |
| `links` | JSON, см. [[LessonLink]] |
| `task_ids` | JSON, задачи занятия |

## Что происходит при закрытии

`POST /api/lessons/:id/status` со `status: done`:
пишется [[LessonAttendance]] всем участникам и списывается занятие
с [[Subscription|абонемента]].

## Тонкость учёта

Занятие попадает в посещаемость, если оно **уже прошло или явно закрыто**
репетитором. Статус важнее расписания — иначе закрытое досрочно занятие
терялось бы в статистике.
