# TaskAttempt — попытка решения

> **Единственный источник статистики.** Одна сущность и для задачи
> на занятии, и для домашней, и для пробника.

## Поля

| поле | смысл |
|---|---|
| `task_id`, `student_id` | что и кто |
| `context` | `lesson` · `homework` · `mock` |
| `lesson_id` / `assignment_id` | откуда пришла |
| `code` | черновик в редакторе, его видит репетитор |
| `answer`, `tries`, `is_correct` | результат |
| `first_try_correct` | верно с первой попытки — честнее общего процента |
| `active_seconds` | **чистое** время, см. ниже |
| `status` | `issued` · `in_progress` · `submitted` · `returned` · `resubmitted` · `checked` |
| `attempt_reviews` | неизменяемые версии ручной проверки |
| `attempt_history` | история переходов и изменённых полей |
| `version` | optimistic concurrency; защищает черновик и проверку от lost update |

Автомат разрешает возврат работы репетитором и повторную отправку, но запрещает
менять `checked`.

## Почему одна сущность

Если задачи занятия и домашние хранить раздельно, статистика соберётся
из двух несводимых источников и проценты разойдутся между экранами.
[[ADR-002 TaskAttempt единая сущность]]

## Про время

`active_seconds` копится, только пока вкладка активна и есть ввод; пауза
через 2 минуты без действий, потолок 6 часов на задачу.
[[ADR-007 Активное время вместо часов на стене]]

## Кто создаёт

Сервер — при прикреплении задачи к [[Lesson|занятию]] или выдаче
[[Assignment|задания]]. Клиент попытки не создаёт.
