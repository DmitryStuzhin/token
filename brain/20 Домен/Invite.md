# Invite — ссылка-приглашение

> Как ученик попадает к репетитору. Одна таблица на три сценария.

## Поля

| поле | смысл |
|---|---|
| `code` | латиница и цифры, без похожих символов — диктуется голосом |
| `kind` | `enrollment` · `group` · `guardian` |
| `tutor_id`, `subject_id`, `group_id` | куда именно зовут |
| `expires_at`, `max_uses`, `used_count` | ограничения |
| `status` | `active` · `used_up` · `revoked` |

## Проверки при приёме

`inviteState()` в `shared/core.js` — общий код для сервера и экрана:

1. отозвано → отказ
2. срок истёк → отказ
3. лимит переходов исчерпан → отказ
4. для группы: нет свободных мест → отказ
5. уже присоединён → отказ

## Что создаёт приём

[[Enrollment]] (индивидуально) или [[GroupMember]] (группа).
`kind: guardian` предусмотрен, но отклоняется: [[Родитель]] не готов.
