# Session — сессия входа

> Случайный токен в таблице + httpOnly-кука `token_sid`. Живёт 30 дней.

## Поля

`token` (32 случайных байта) · `user_id` · `created_at` · `expires_at` · `user_agent`

## Почему в БД, а не в JWT

Сессию нужно уметь **отзывать** — при выходе строка удаляется, и токен
мгновенно перестаёт работать. С JWT пришлось бы держать чёрный список,
то есть ту же таблицу, только сложнее.

## Почему httpOnly

Клиентский JavaScript куку не читает — значит, украсть её через XSS
нельзя. Ни один экран не знает токена: см. [[Клиент]].
