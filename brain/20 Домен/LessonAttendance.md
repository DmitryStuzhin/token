# LessonAttendance — посещаемость

> Строка на **каждого ученика** занятия. Ключ — `lesson_id + student_id`.

## Значения

`present` · `late` · `absent` · `moved`

## Зачем построчно

Для индивидуального занятия хватило бы статуса самого [[Lesson|занятия]].
Но на групповом один пришёл, другой нет — общего статуса недостаточно.

Если строки нет, `attendanceOf()` выводит статус из занятия:
`done → present`, `missed → absent`, `moved → moved`.
