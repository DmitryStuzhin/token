# User — учётная запись

> Один человек = одна запись. Роль выбирается при регистрации и не меняется.

## Поля

| поле | смысл |
|---|---|
| `role` | `student` · `tutor` · `parent` |
| `email` | уникальный, он же логин |
| `pass_hash` + `pass_salt` | scrypt, соль на каждого |
| `tz` | часовой пояс, берётся из браузера |

## Что висит рядом

- [[StudentProfile]] или [[TutorProfile]] — по одному на роль
- [[Session]] — активные входы
- [[NotificationPref]] — настройки уведомлений

## Кто создаёт

[[Регистрация и вход]] → `POST /api/auth/register`

## Тонкость

Пароль никогда не хранится и не передаётся в открытом виде, но соль и хеш
лежат в SQLite рядом с данными. Для боевой версии этого мало — см. [[Риски]].
