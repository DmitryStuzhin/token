# Внутренние события

> Версионированные факты домена, пока доставляемые только внутри Node-процесса.

Envelope v1: `eventId`, `eventName`, `eventVersion`, `occurredAt`,
`aggregateId`, `correlationId`, `payload`.

Реализованы `UserRegistered`, `InviteAccepted`, `LessonCompleted`,
`AssignmentPublished`, `AttemptChecked`. HTTP route не отправляет уведомление и
не пересчитывает аналитику напрямую: подписчики реагируют через dispatcher.
