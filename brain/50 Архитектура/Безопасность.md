# Безопасность

## Проверки репозитория

GitHub Actions запускает Gitleaks, `npm audit --audit-level=high`, проверку
лицензий и полный quality-набор. GitHub Dependency Review не запускается, пока
репозиторий не предоставляет Dependency Graph API. Единственное исключение Gitleaks —
фиксированная строка `api-v1-lesson-key` в интеграционном тесте; она помечена
inline-комментарием `gitleaks:allow`, а историческая находка старого коммита
ограничена точным fingerprint в `.gitleaksignore`.

> Что сделано и чего не хватает для боевой версии.

## Сделано

| Мера | Где |
|---|---|
| Новые пароли хешируются Argon2id; scrypt обновляется при входе | `modules/identity/application/auth-service.js` |
| Сессия в secure/httpOnly-куке, `sameSite: lax` | `server/auth.js` |
| HSTS, запрет framing/MIME sniffing и строгий CSP без inline/eval в приложении | `server/security.js` |
| Skulpt изолирован в opaque-origin iframe с отдельным узким CSP | [[ADR-013 Изоляция браузерного Python-runner]] |
| Проверка Origin для cookie-auth команд | `server/security.js` |
| Rate limit входа, регистрации и приглашений | `server/app.js` |
| Рекурсивное скрытие PII, ответов и токенов в structured logs | `server/logger.js` |
| Отзыв сессии при выходе | таблица `sessions` |
| Подтверждение email до первого входа, ссылка 24 часа | `account_tokens`, SMTP |
| Одноразовый сброс пароля на 30 минут с отзывом всех сессий | `AuthService.resetPassword` |
| Список активных устройств и точечный/массовый отзыв | `/api/v1/auth/sessions` |
| Журнал событий регистрации, входа и восстановления | `security_events` |
| Обязательный MFA административной роли без trusted-device bypass | `AuthService`, email-код |
| Версионированные квитанции обязательных согласий | `user_consents`, `/privacy.html`, `/terms.html` |
| Deny-by-default матрица и object policies | `modules/identity/application/access-policy.js` |
| Audit чувствительных чтений и предметных изменений | `server/audit.js`, `security_events` |
| Гость не получает разметку кабинета | `server/index.js` |
| Роль и владение проверяются на каждом маршруте | `server/api.js` |
| WebSocket авторизуется той же кукой | `server/live.js` |
| Эталонные ответы не покидают сервер | [[ADR-006 Ответы не покидают сервер]] |
| Экранирование вывода `UI.esc` | `public/assets/ui.js` |

## Не сделано

- **Распределённый rate limit**: текущий счётчик локален одному процессу

Подробно с оценкой — [[Риски]].
