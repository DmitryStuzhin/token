# База данных

> SQLite через `better-sqlite3`, синхронный доступ. Файл `data/token.db`.

## 19 таблиц

`users` `sessions` `student_profiles` `tutor_profiles` `subjects` `topics`
`tasks` `enrollments` `groups` `group_members` `invites` `lessons`
`lesson_attendance` `assignments` `attempts` `goals` `subscriptions`
`notification_prefs` `mock_exams`

Соответствие сущностям — [[Домен]].

## Справочники

Предметы, темы и банк задач заполняются при первом запуске из
`shared/domain.js`. Задачи **генерируются**, а не вбиты руками.

## Два способа читать

| функция | что отдаёт | кому |
|---|---|---|
| `snapshot(user)` | срез под пользователя | уходит на клиент |
| `fullState()` | всё без фильтров | только внутренняя логика |

Смешивать нельзя: `fullState` содержит эталонные ответы задач.
Однажды это уже привело к ошибке — приглашения не находились, потому что
проверка шла по срезу вместо полного состояния. См. [[Не сделано]].

## Почему SQLite

Один процесс, десятки пользователей, файл рядом с кодом.
PostgreSQL понадобится при нескольких процессах — [[Масштабирование]].
