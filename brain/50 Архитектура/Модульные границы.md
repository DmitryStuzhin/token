# Модульные границы

> Бизнес-правила отделены от HTTP и конкретной БД; физически платформа остаётся одним процессом.

## Направление зависимостей

`server/http → application → domain`, а `infrastructure` реализует порты
application и подключается в composition root. Циклы и обратные импорты
проверяет `dependency-cruiser`.

Доменные модули: identity, relationships, scheduling, learning, content,
analytics. Общие ошибки, policy, event envelope и dispatcher находятся в
`modules/shared`.

## Конкурентная запись

[[Invite]], [[Lesson]], [[Assignment]] и [[TaskAttempt]] имеют `version`.
SQLite и PostgreSQL adapters реализуют один асинхронный repository contract и
обновляют агрегаты через compare-and-swap. Контрактный тест подтверждает
одинаковый конфликт HTTP 409 без lost update.

Composition root выбирает инфраструктуру через `DATABASE_DRIVER`. Production
путь создаёт пул PostgreSQL и не импортирует SQLite.

## События

`UserRegistered`, `InviteAccepted`, `LessonCompleted`, `AssignmentPublished`,
`AttemptChecked` доставляются [[Внутренние события|in-process dispatcher]].
Контракт готов к будущему outbox без подключения Kafka на текущей нагрузке.
