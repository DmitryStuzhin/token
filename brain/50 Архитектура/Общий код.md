# Общий код

> `shared/` исполняется и на сервере, и в браузере. Один расчёт — одна правда.

## domain.js

Предметы с сеткой экзамена, темы, **генератор банка задач**.
Сервер вызывает его при первом запуске, чтобы наполнить БД.

## core.js

`createCore(state)` возвращает выборки и агрегаты над снимком данных:
`kpi`, `topicMastery`, `dailyActivity`, `taskNumberStats`, `attendance`,
`assignmentsOf`, `groupStats`, `inviteState`, `checkAnswer`.

**Мутаций нет** — менять данные вправе только сервер.

## Зачем так

Если бы статистику считали дважды — на сервере для API и в браузере для
экрана, — расхождение было бы вопросом времени. Общий код исключает
целый класс ошибок.

## Ограничение

`checkAnswer` работает только там, где есть эталон, то есть на сервере:
в браузерном срезе поля `answer` нет.
