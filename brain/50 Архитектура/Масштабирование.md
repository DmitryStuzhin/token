# Масштабирование

> Где сейчас запас и что упрётся первым.

## Заложено вширь

| Что | Как |
|---|---|
| Новый предмет | запись в `subjects` с сеткой — [[ADR-003 Предмет как данные]] |
| Новый ученик | сам по [[Invite|ссылке]] |
| Группы | [[Group]] как контейнер, статистика по ученикам |
| Новые задачи | импорт JSON в [[Task]] |

## Что упрётся первым

1. **Пересчёт агрегатов на каждый запрос.** Лечится материализованными
   представлениями; сигнатуры функций уже под это подобраны.
2. **SQLite при нескольких процессах.** Один писатель. Лечится переездом
   на PostgreSQL — слой чтения изолирован в `server/db.js`.
3. **WebSocket в памяти одного процесса.** Комнаты живут в `Map`.
   При нескольких процессах понадобится общая шина.
4. **Отсутствие фоновых задач.** Напоминания и «просрочено» сейчас
   считаются при чтении, а не по расписанию.

## Порядок действий при росте

Вынести фоновые задачи → материализовать агрегаты → PostgreSQL →
разделить процессы. Это путь «вариант A → вариант B» из `docs/ARCHITECTURE.md`.
