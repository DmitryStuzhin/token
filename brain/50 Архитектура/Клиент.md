# Клиент

> Обычные страницы без сборки. Никакого состояния своего не держит.

## Как страница стартует

```html
<script src="/api/state.js"></script>   <!-- срез с сервера -->
<script src="/shared/core.js"></script> <!-- общие выборки -->
<script src="/assets/store.js"></script><!-- Core над срезом -->
<script src="/assets/api.js"></script>  <!-- действия -->
<script src="/assets/auth.js"></script> <!-- кто вошёл -->
<script src="/assets/ui.js"></script>   <!-- оболочка -->
```

Срез приходит тегом `<script>`, поэтому страница рисуется синхронно —
без мигания пустым экраном.

## Файлы

| файл | роль |
|---|---|
| `store.js` | `Core` над `window.__STATE__`, только чтение |
| `api.js` | все действия, `fetch` с куками |
| `auth.js` | кто вошёл, редирект не на свою страницу |
| `ui.js` | сайдбар по роли, хелперы вёрстки |
| `app.css` | оформление, светлая и тёмная тема |

## Чего на клиенте нет

localStorage с данными, эталонных ответов, токенов сессии, проверок прав
как единственного рубежа.
